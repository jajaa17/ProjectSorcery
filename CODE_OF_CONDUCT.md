# Code of Conduct

Project Sorcery is a hobby project made for fun. Keep it that way for everyone.

- Be respectful and welcoming to people of every background and experience level. Lots of contributors are new to Unity, C# or open source.
- Critique code and ideas, never people. Assume good intent.
- No harassment, hate speech, sexual content, doxxing or personal attacks, in issues, pull requests, discussions or anywhere else the project lives.
- Don't post spoilers in issue titles. Use spoiler tags in the body if you need to discuss story details.
- Respect the maintainers' decisions on what gets merged. You are always free to take it in your own direction in a fork.

Maintainers may edit, hide or delete content and block anyone who breaks these rules. To report a problem privately, contact the maintainer through their GitHub profile.
